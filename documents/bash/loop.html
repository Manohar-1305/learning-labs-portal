Bash Loops

Loops are used to execute a block of commands repeatedly. Bash provides different types of loops. Let's learn the basics.

1. For Loop

A for loop executes commands for each item in a list.

#!/bin/bash

for name in Linux Docker Kubernetes
do
    echo "Learning $name"
done

Output

Learning Linux
Learning Docker
Learning Kubernetes

2. While Loop

A while loop executes commands as long as the condition is true. 

#!/bin/bash

count=1

while [ $count -le 5 ]
do
    echo "Count: $count"
    count=$((count + 1))
done

Output

Count: 1
Count: 2
Count: 3
Count: 4
Count: 5

3. Until Loop

An until loop executes commands until the condition becomes true. 

#!/bin/bash

count=1

until [ $count -gt 5 ]
do
    echo "Count: $count"
    count=$((count + 1))
done

4. Break and Continue

break stops the loop. continue skips the current iteration. 

#!/bin/bash

for number in 1 2 3 4 5
do
    if [ $number -eq 3 ]
    then
        continue
    fi

    echo "$number"
done

Output

1
2
4
5

5. Practical Exercise

  1. Print numbers from 1 to 10 using a for loop.
  2. Print numbers from 1 to 5 using a while loop.
  3. Print the names of five Linux commands using a for loop.
  4. Use break to stop a loop when the number reaches 4.
Important: Always ensure that the loop condition eventually becomes false. Otherwise, you may create an infinite loop.
