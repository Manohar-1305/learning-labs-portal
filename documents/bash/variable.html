Bash Scripting - Variables

A variable is used to store information such as text, numbers, file paths, and command outputs.

1. Creating Variables

Use the following syntax to declare a variable:

variable_name=value

Example:

name="Manohar"
age=30
city="Hyderabad"

echo "$name"
echo "$age"
echo "$city"
Important: Do not add spaces before or after the = operator when assigning variables.

2. Accessing Variables

Use the dollar sign ($) to access a variable.

course="Linux"

echo "$course"
echo "I am learning $course"

Expected Output

Linux
I am learning Linux

3. Variable Naming Rules

  • Variable names are case-sensitive.
  • Names can contain letters, numbers, and underscores.
  • Names cannot start with a number.
  • Names cannot contain spaces.
user_name="admin"
USER_NAME="root"
server1="ubuntu"

echo "$user_name"
echo "$USER_NAME"
echo "$server1"

4. Read-Only Variables

The readonly command prevents a variable from being modified. 

readonly COMPANY="Learning Portal"

echo "$COMPANY"

COMPANY="New Company"

The final command produces an error because the variable is read-only.

5. Environment Variables

Environment variables are available to processes started from the current shell. 

echo "$HOME"
echo "$USER"
echo "$PATH"
echo "$SHELL"

Create an environment variable:

export APP_ENV="development"

echo "$APP_ENV"

Verify it in a child Bash process:

bash -c 'echo "$APP_ENV"'

6. Local vs Environment Variables

Local Shell Variable Environment Variable
Created using assignment Exported using export
Available in the current shell Inherited by child processes
Example: name="Linux" Example: export name="Linux"

7. Taking User Input

Use the read command to accept input. 

read -p "Enter your name: " name

echo "Welcome $name"

8. Command Substitution

Store the output of a command inside a variable using $(command). 

current_date=$(date)
hostname=$(hostname)
current_user=$(whoami)

echo "Date: $current_date"
echo "Hostname: $hostname"
echo "User: $current_user"

9. Arithmetic with Variables

Use $(( )) to perform integer arithmetic. 

num1=10
num2=20

sum=$((num1 + num2))
difference=$((num2 - num1))
product=$((num1 * num2))

echo "Sum: $sum"
echo "Difference: $difference"
echo "Product: $product"

10. Special Variables

Variable Description
$0 Script name or invocation path
$1 First positional argument
$2 Second positional argument
$# Number of positional arguments
$@ All positional arguments
$? Exit status of previous command
$$ Current shell process ID

Example

Create a file named arguments.sh:

#!/bin/bash

echo "Script: $0"
echo "First argument: $1"
echo "Second argument: $2"
echo "Total arguments: $#"

Run:

bash arguments.sh Linux DevOps

11. Default Variable Values

Use ${variable:-default} to provide a fallback when a variable is unset or empty. 

username=""

echo "${username:-guest}"

Expected Output

guest

12. Removing Variables

Use unset to remove a variable. 

course="Bash"

echo "$course"

unset course

echo "$course"

read -p "Enter your name: " name
read -p "Enter your course: " course

current_date=$(date)
current_user=$(whoami)

Execute the script:

bash variables.sh
