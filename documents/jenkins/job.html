Jenkins: Create Your First Job

In this practical exercise, you will create your first Jenkins Freestyle project, configure a build step, execute the job, and inspect the build console output.

Prerequisites:
  • Jenkins server must be running.
  • You must be logged in to Jenkins.
  • You must have Jenkins administrator or job creation permissions.

1. Understanding Jenkins Jobs

A Jenkins job is a configured task that Jenkins executes. It can compile code, run tests, build Docker images, deploy applications, or execute shell scripts.

Common Jenkins job types include:

Job Type Purpose
Freestyle Project Configure builds using a graphical interface.
Pipeline Define CI/CD workflows using a Jenkinsfile.
Multibranch Pipeline Automatically discover and build branches containing Jenkinsfiles.
Folder Organize Jenkins jobs into folders.

2. Open Jenkins Dashboard

Step 1 Open your Jenkins URL in a browser.
Step 2 Log in using your Jenkins administrator credentials.
Step 3 You should see the Jenkins Dashboard.

3. Create Your First Freestyle Job

Step 1 Click New Item on the Jenkins dashboard.
Step 2 Enter the following job name: 
first-jenkins-job
Step 3 Select Freestyle project.
Step 4 Click OK.
Jenkins will open the configuration page for your new job.

4. Configure General Settings

In the General section, enter a description: 

My first Jenkins job for learning CI/CD automation.

Leave the remaining settings at their defaults for this exercise.

5. Configure Build Steps

Scroll down to the Build Steps section.

Step 1 Click Add build step.
Step 2 Select Execute shell.
Step 3 Enter the following shell commands: 
#!/bin/bash

echo "================================="
echo "Welcome to Jenkins"
echo "================================="

echo "Job Name: $JOB_NAME"
echo "Build Number: $BUILD_NUMBER"

echo "Checking system information..."

hostname
date
whoami

echo "Jenkins build completed successfully."
Important: Jenkins automatically provides environment variables such as JOB_NAME and BUILD_NUMBER during job execution.

6. Save the Job

Step 1 Scroll to the bottom of the configuration page.
Step 2 Click Save.

Jenkins will redirect you to the job dashboard.

7. Execute the Jenkins Job

Step 1 Click Build Now from the left-side menu.
Step 2 Look at the Build History section.
Step 3 Click the newly generated build number, such as #1.
Step 4 Click Console Output.

8. Expected Console Output

Your output should look similar to this:

Started by user admin
Running as SYSTEM
Building in workspace /var/jenkins_home/workspace/first-jenkins-job

=================================
Welcome to Jenkins
=================================

Job Name: first-jenkins-job
Build Number: 1

Checking system information...

jenkins-server
Current date and time
jenkins

Jenkins build completed successfully.

Finished: SUCCESS
Result: If the console displays Finished: SUCCESS, your first Jenkins job has completed successfully.

9. Understanding Build Status

Status Meaning
Success Build completed successfully.
Failure Build encountered an error.
Unstable Build completed but one or more tests or configured checks failed.
Aborted Build was manually or programmatically stopped.

10. Practical Exercises

Complete these exercises independently:

  1. Create a Freestyle job named linux-system-info.
  2. Display the hostname and operating system information.
  3. Display available disk space using df -h.
  4. Display memory information using free -h.
  5. Execute the job three times.
  6. Inspect the build history and console output.
  7. Modify the shell script and execute the job again.

11. Troubleshooting

Build fails immediately

Open Console Output and identify the failing command. Verify that the shell commands are supported inside the Jenkins container.

Permission denied

Check the user running the Jenkins build and the permissions of the workspace or files being accessed.

Build remains in the queue

Check whether Jenkins has an available executor and whether the build is waiting for an agent.
